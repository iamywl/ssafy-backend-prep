Q01 WHERE 절 vs HAVING 절의 차이점 2대 관점 비교 서술
★★★★★ 서술형 출제 1순위 (공지 적시) SQL 기본 및 DML
[출제 유형: 주관식 서술형 (배점 10.25점)]
SQL에서 WHERE 절과 HAVING 절의 차이점을 다음 두 가지 관점에서 비교하여 서술하시오. ① 조건 적용 시점(그룹화 전/후) ② 집계 함수 사용 가능 여부
📊 실전 이해를 돕는 시각화 SVG 다이어그램
🎯 모범 정답 (Model Answer)
<WHERE 절>
① 조건 적용 시점: 데이터를 그룹화(GROUP BY)하기 전에 개별 행(Row)을 필터링한다.
② 집계 함수: 사용할 수 없다 (예: WHERE SUM(price) > 1000 사용 불가).

<HAVING 절>
① 조건 적용 시점: 데이터를 그룹화(GROUP BY)한 후 만들어진 그룹을 필터링한다.
② 집계 함수: 사용할 수 있다 (예: HAVING COUNT(*) >= 5, HAVING AVG(score) >= 80 등).
💡 퍼펙트 상세 해설 및 시험장 함정 탈출 팁
  • SQL 쿼리 실제 실행 순서: FROM ➔ ON ➔ JOIN ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ SELECT ➔ DISTINCT ➔ ORDER BY ➔ LIMIT
  • 왜 WHERE에서 집계함수가 불가능한가?: WHERE 절은 행 단위 데이터를 읽어오는 초기 단계이므로, 아직 그룹이 형성되지 않아 집계 연산(SUM, AVG 등) 자체가 계산되지 않은 상태이기 때문입니다.
  • 시험장 암기 공식: 「행 먼저 WHERE, 묶고 나서 HAVING, 집계는 HAVING만!」
Q02 forward vs sendRedirect 비교 서술
★★★★★ 서술형 출제 1순위 (공지 적시) Servlet & JSP 아키텍처
[출제 유형: 주관식 서술형 (배점 10.25점)]
서블릿/JSP 화면 이동 메커니즘인 forward와 sendRedirect의 차이점을 다음 3가지 관점에서 비교하여 서술하시오. ① 요청/응답 왕복 횟수 ② 브라우저 URL 변경 여부 ③ request 속성(Attribute) 공유 여부
📊 실전 이해를 돕는 시각화 SVG 다이어그램
🎯 모범 정답 (Model Answer)
<forward>
1. 요청/응답 왕복 횟수: 1회 (클라이언트 모르게 서버 내부에서 제어권 이동)
2. 브라우저 URL 변경 여부: X (처음 클라이언트가 요청한 URL 그대로 유지)
3. request 속성 공유 여부: O (request.setAttribute() 데이터가 목적지 JSP까지 그대로 유지)

<sendRedirect>
1. 요청/응답 왕복 횟수: 2회 (서버가 302 응답 ➔ 브라우저가 새 주소로 재요청)
2. 브라우저 URL 변경 여부: O (이동한 최종 새 주소로 브라우저 주소창이 변경됨)
3. request 속성 공유 여부: X (완전히 새로운 HTTP 요청이 발생하므로 기존 request 속성은 초기화/소멸)
💡 퍼펙트 상세 해설 및 시험장 함정 탈출 팁
  • 조회(Read) vs 변경(CUD) 패턴: 목록 조회/상세 조회는 request에 데이터를 담아 JSP로 넘겨야 하므로 forward를 쓰고, 등록/수정/삭제 후에는 중복 요청(새로고침 버그)을 막기 위해 sendRedirect(PRG 패턴)를 사용합니다.
  • 구현 문법: 
    // forward:
request.getRequestDispatcher("/gear/list.jsp").forward(request, response);

// sendRedirect:
response.sendRedirect(request.getContextPath() + "/gear?action=list");

관계형 데이터베이스의 제1정규화(1NF), 제2정규화(2NF), 제3정규화(3NF)의 핵심 정의와 제거하는 이상 현상을 서술하시오.

🎯 모범 정답 (Model Answer)

제1정규화 (1NF) ★ [중요]: 테이블의 모든 컬럼은 여러 값이 아닌 더 이상 쪼갤 수 없는 단일 값(원자값, Atomic Value)만을 갖는다.

제2정규화 (2NF): 1NF를 만족하면서, 복합 기본키의 일부 컬럼에만 종속되는 것을 분리하여 부분 함수 종속성(Partial Functional Dependency)을 제거한다. (기본키 전체에 완전 함수 종속)

제3정규화 (3NF): 2NF를 만족하면서, 기본키가 아닌 일반 컬럼들끼리 꼬리를 물고 종속되는 이행적 함수 종속성(Transitive Functional Dependency, A➔B, B➔C)을 제거한다.

💡 퍼펙트 상세 해설 및 시험장 함정 탈출 팁
  • 원자값 위반 예시: 한 학생의 [수강과목] 컬럼에 'Java, DB, Spring'처럼 쉼표로 여러 값을 넣으면 1NF 위반! ➔ 행을 분리하여 원자값으로 만들어야 합니다.
  • 암기 키워드: 「1원(원자값) ➔ 2부(부분종속제거) ➔ 3이(이행종속제거) ➔ 보결(BCNF 결정자 후보키)」

Q05 트랜잭션 SAVEPOINT (저장점) 및 부분 롤백
★★★★★ 100% 빈출 (부분 롤백) 트랜잭션 및 고급 SQL
[출제 유형: 고급 SQL & 실전 쿼리 예측]
트랜잭션에서 SAVEPOINT의 기능과 ROLLBACK TO 문법의 동작 원리를 설명하시오.
📊 실전 이해를 돕는 시각화 SVG 다이어그램
🎯 모범 정답 (Model Answer)
정의 ★ [중요]
데이터베이스 트랜잭션 작업 중 특정 지점을 기록(저장)해두어, 문제가 발생했을 때 전체 작업 취소(Rollback)가 아닌 해당 지점까지만 '부분 취소'를 할 수 있게 해주는 기능이다.

동작 예시:
1번 데이터 수정 성공 ➔ SAVEPOINT SP1; (중간 저장)
2번 데이터 수정 시도 중 오류 발생! ➔ ROLLBACK TO SP1; 실행
👉 결과: 1번 데이터 수정은 정상 유지되고, 오류가 난 2번 작업만 깔끔하게 취소됨!
💡 퍼펙트 상세 해설 및 시험장 함정 탈출 팁
  • 주의 문법: ROLLBACK;만 쓰면 트랜잭션 전체가 취소되지만, ROLLBACK TO 세이브포인트명;을 쓰면 해당 저장점 이후의 작업만 부분 취소됩니다.
  • 시험 함정: ROLLBACK TO SP1 실행 후에도 트랜잭션은 종료된 것이 아니므로, 최종 반영을 위해서는 반드시 COMMIT;을 호출해야 합니다.

클러스터드 인덱스(Clustered Index)와 세컨더리 인덱스(Secondary Index)의 물리적 구조 및 성능 특징을 비교하시오.
📊 실전 이해를 돕는 시각화 SVG 다이어그램
🎯 모범 정답 (Model Answer)
① 클러스터드 인덱스 (Clustered Index):
인덱스의 기준값 순서와 실제 데이터 행이 동일한 순서로 물리적 정렬되어 저장된다. (리프 노드 = 실제 데이터 페이지).

② 세컨더리 인덱스 (Secondary Index, 보조 인덱스):
실제 데이터의 물리적 위치와 무관하게 인덱스 목차만 따로 관리하며(리프 노드 = PK 값 또는 포인터), 테이블당 여러 개 생성이 가능하고 데이터 수정 시 오버헤드가 적다.
단, 실제 행 데이터를 찾기 위해 포인터를 통해 한 번 더 클러스터드 인덱스로 이동(Double Lookup)해야 하므로 검색 속도가 상대적으로 느리다.
💡 퍼펙트 상세 해설 및 시험장 함정 탈출 팁

3 & 4. SQL 기본, DDL/DML, 트랜잭션, 고급 서브쿼리
핵심 개념 시험 필수 암기 내용
DELETE vs TRUNCATE vs DROP • DELETE: DML, WHERE 절 가능, 행 단위 삭제, 롤백(Undo) 가능, 느림
• TRUNCATE: DDL, 전체 행 고속 삭제, 테이블 구조 유지, 롤백 불가
• DROP: DDL, 테이블 구조 및 데이터 완전 삭제, 롤백 불가
외래키 제약조건 삭제 ALTER TABLE 테이블명 DROP FOREIGN KEY 제약조건명; (MySQL 문법)
삼치 논리와 NULL 연산 SQL은 True, False, Unknown 3가지 논리 상태. NULL = NULL ➔ Unknown!
NULL 검사는 반드시 IS NULL 또는 IS NOT NULL 사용
LIMIT & 문자열 결합 페이징: LIMIT 시작위치(0부터), 개수 (예: 3페이지 LIMIT 20, 10)
문자열 결합: CONCAT(str1, str2, ...)
트랜잭션 부분 롤백 SAVEPOINT 포인트명; ➔ ROLLBACK TO SAVEPOINT 포인트명;
다중 행 / 스칼라 서브쿼리 • 스칼라 서브쿼리: SELECT 절 위치, 단 1행 1열만 반환
• 다중 행 연산자: IN, ANY/SOME(하나라도 만족), ALL(모두 만족)
• 상호 연관 서브쿼리: 메인 쿼리 컬럼을 서브쿼리가 참조. 존재 여부 검사는 EXISTS / NOT EXISTS
차집합 & 뷰(View) 차집합: EXCEPT (또는 NOT IN/NOT EXISTS)
뷰: 디스크에 저장되지 않는 가상 테이블. 집계함수/GROUP BY/DISTINCT 포함 시 DML(INSERT/UPDATE) 제한
5, 6, 7. DB 설계/인덱스 & 주관식 서술형 2대 테마 비교
핵심 개념 시험 필수 암기 내용
정규화 단계 • 1NF: 모든 속성의 도메인이 원자값(Atomic value)
• 2NF: 1NF 만족 + 부분 함수적 종속 제거 (완전 함수적 종속)
• 3NF: 2NF 만족 + 이행적 함수적 종속 제거 (A➔B, B➔C 제거)
• BCNF: 모든 결정자가 후보키
Clustered vs Secondary Index • Clustered Index: 기본키(PK) 기준 실제 데이터 행이 물리적으로 정렬되어 리프 노드에 저장 (테이블당 1개)
• Secondary Index: 보조 인덱스, 리프 노드에 실제 데이터가 아닌 PK 주소를 저장 (테이블당 여러 개 가능)
[서술형 1] forward vs sendRedirect ① 요청/응답 왕복: forward는 서버 내부 이동으로 1회, sendRedirect는 302 응답 후 브라우저 재요청으로 2회
② URL 변경: forward는 URL 불변, sendRedirect는 새 URL로 변경
③ request 속성 공유: forward는 request 객체 유지되어 공유 가능, sendRedirect는 새 request 생성되어 공유 불가
[서술형 2] WHERE 절 vs HAVING 절 ① 조건 적용 시점: WHERE는 GROUP BY 그룹화 전 개별 행(Row)에 적용, HAVING은 GROUP BY 그룹화 후 집계 그룹에 적용
② 집계 함수 사용: WHERE는 집계 함수(COUNT, SUM 등) 사용 불가, HAVING은 집계 함수 사용 가능

@WebServlet({"/gear", "/member"}) // [필수 1] 서블릿 URL 매핑
public class GearController extends HttpServlet implements ControllerHelper {
    private final GearService service = GearServiceImpl.getInstance();

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String action = getActionParameter(request, response);
        
        switch (action) {
            case "index" -> redirect(request, response, "/index.jsp");
            case "list" -> list(request, response);
            case "detail" -> detail(request, response);   // [CRD] 상세조회
            case "delete" -> delete(request, response);   // [CRD] 삭제
            case "regist-form" -> forward(request, response, "/gear/regist.jsp");
            case "login-form" -> forward(request, response, "/login-form.jsp");
            case "logout" -> logout(request, response);
            default -> response.sendError(HttpServletResponse.SC_NOT_FOUND); // 404 처리
        }
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String action = getActionParameter(request, response);
        switch (action) {
            case "regist" -> regist(request, response);
            case "login" -> login(request, response);
            case "delete" -> delete(request, response);
            default -> response.sendError(HttpServletResponse.SC_NOT_FOUND);
        }
    }

    // 1. 목록 조회
    private void list(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        List<Gear> gearList = service.selectAll();
        req.setAttribute("gearList", gearList); // JSP에서 쓸 이름으로 저장
        forward(req, resp, "/gear/list.jsp");
    }

    // 2. 상세 조회
    private void detail(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        String code = req.getParameter("code");
        Gear gear = service.selectByCode(code);
        req.setAttribute("gear", gear);
        forward(req, resp, "/gear/detail.jsp");
    }

    // 3. 제품 삭제
    private void delete(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        String code = req.getParameter("code");
        service.deleteByCode(code);
        redirect(req, resp, "/gear?action=list"); // 삭제 후 목록으로 리다이렉트
    }

    // 4. 제품 등록
    private void regist(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        String code = req.getParameter("code");
        String name = req.getParameter("name");
        int price = Integer.parseInt(req.getParameter("price"));
        String brand = req.getParameter("brand");
        String color = req.getParameter("color");
        service.insert(new Gear(code, name, price, brand, color));
        redirect(req, resp, "/gear?action=list"); // 등록 후 목록으로 리다이렉트
    }

    // 5. 로그인 (세션 & 쿠키)
    private void login(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        String email = req.getParameter("email");
        String pass = req.getParameter("pass");
        String rememberMe = req.getParameter("remember-me");

        Member member = service.login(email, pass);
        if (member != null) {
            req.getSession().setAttribute("loginUser", member); // [세션 저장]
            if (rememberMe != null) { // [쿠키 저장]
                setupCookie("rememberEmail", email, 60*60*24*7, req.getContextPath(), resp);
            } else { // [쿠키 삭제]

package com.ssafy.sample.controller;

import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.List;
import com.ssafy.sample.model.dto.Gear;
import com.ssafy.sample.model.dto.Member;
import com.ssafy.sample.model.service.GearService;
import com.ssafy.sample.model.service.GearServiceImpl;

@WebServlet({"/gear", "/member"})
public class GearController extends HttpServlet implements ControllerHelper {
    private static final long serialVersionUID = 1L;
    private final GearService service = GearServiceImpl.getInstance();

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String action = getActionParameter(request, response);
        switch (action) {
            case "index" -> redirect(request, response, "/index.jsp");
            case "list" -> list(request, response);
            case "regist-form" -> forward(request, response, "/gear/regist.jsp");
            case "login-form" -> forward(request, response, "/login-form.jsp");
            case "logout" -> logout(request, response);
            default -> response.sendError(HttpServletResponse.SC_NOT_FOUND);
        }
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String action = getActionParameter(request, response);
        switch (action) {
            case "regist" -> regist(request, response);
            case "login" -> login(request, response);
            default -> response.sendError(HttpServletResponse.SC_NOT_FOUND);
        }
    }

    private void list(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        List<Gear> gearList = service.selectAll();
        request.setAttribute("gearList", gearList);
        forward(request, response, "/gear/list.jsp");
    }

    private void regist(HttpServletRequest request, HttpServletResponse response) throws IOException {
        String code = request.getParameter("code");
        String name = request.getParameter("name");
        int price = Integer.parseInt(request.getParameter("price"));
        String brand = request.getParameter("brand");
        String color = request.getParameter("color");
        service.insert(new Gear(code, name, price, brand, color));
        redirect(request, response, "/gear?action=list");
    }

    private void login(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String email = request.getParameter("email");
        String pass = request.getParameter("pass");
        String rememberMe = request.getParameter("remember-me");
        Member member = service.login(email, pass);

        if (member != null) {
            request.getSession().setAttribute("loginUser", member);
            if (rememberMe != null) {
                setupCookie("rememberEmail", email, 60 * 60 * 24 * 7, request.getContextPath(), response);
            } else {
                setupCookie("rememberEmail", "", 0, request.getContextPath(), response);
            }
            redirect(request, response, "/gear?action=index");
        } else {
            request.setAttribute("alertMsg", "로그인 실패! 이메일과 비밀번호를 확인하세요.");
            forward(request, response, "/login-form.jsp");
        }
    }

    private void logout(HttpServletRequest request, HttpServletResponse response) throws IOException {
        request.getSession().invalidate();
        redirect(request, response, "/gear?action=index");
    }
}
